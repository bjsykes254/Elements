What this tool doesn't cover

  • Evidence and proof. What facts show that an element is met, and how strong the proof has to be at each stage of a case.
  • Defenses and excuses, such as self-defense, except where they are part of an offense's definition.
  • How charges are chosen. One event can fit several offenses, and prosecutors and courts decide which apply. Practices differ by office.
  • Sentencing. Only the offense class is shown, not how a sentence is worked out.
  • Any real situation. This is general information, not legal advice. For a real situation, talk to a lawyer.
